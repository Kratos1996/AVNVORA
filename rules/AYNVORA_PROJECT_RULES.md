# AYNVORA Project Rules

These rules apply to all work in the AYNVORA SDK repository.

1. AYNVORA is a Kotlin Multiplatform + Compose Multiplatform SDK.
2. The Master UI Style Guide is the single source of truth for all UI.
3. Do not invent colors, typography, spacing, radius, motion, icons, or components. Use only values and patterns defined by the Master UI Style Guide.
4. Astro Engine must remain independent from UI and Compose dependencies.
5. Keep the architecture offline-first.
6. Do not add fake astrology calculations or placeholder calculations that could be mistaken for real results. Clearly identify any non-calculating foundation or unsupported operation.
7. Keep public SDK APIs separate from internal implementation.
8. Follow clean modular architecture and keep dependency direction explicit.
9. Do not add unnecessary dependencies.
10. Do not make large architectural changes without explaining the proposed change first.
