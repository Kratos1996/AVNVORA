# AYNVORA Versioning & Releases
Version: 1.0

## Version Types
- product/SDK version
- module version where independently published
- data/rules version
- API contract version
- Design System version

## Release Requirements
Every release should record:
- changes
- breaking changes
- migrations
- security changes
- data/rule changes
- compatibility
- test status

## Astrology Data
Calculation results are reproducible only when the relevant engine/rule/data versions are known.
