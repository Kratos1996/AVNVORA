# AYNVORA Component Library
Version: 1.0

## Reuse Rule
Search and reuse an existing component before creating a new one.

## Component Contract
Every reusable component documents:
- purpose
- anatomy
- parameters
- tokens used
- visual states
- accessibility behavior
- platform differences
- examples
- tests

## Required States
Default, pressed, focused, selected, disabled, loading, error, success and empty where applicable.

## Initial Families
Buttons, cards, inputs, chips, tabs, dialogs, sheets, lists, navigation, charts, planet cards, zodiac selectors, report sections.

## Duplication Rule
If two components solve the same problem, consolidate rather than maintain parallel implementations.
