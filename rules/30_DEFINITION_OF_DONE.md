# AYNVORA Definition of Done
Version: 1.1

A feature is done only when applicable items are complete:
- [ ] Specification updated
- [ ] Existing functionality/components searched and reused
- [ ] Architecture boundaries preserved
- [ ] Security/privacy reviewed
- [ ] Design System followed (including `sdp` and `ssp` scalable tokens)
- [ ] Verified across mobile, foldable, tablet, and desktop form factors
- [ ] Loading/empty/error/success/disabled states handled
- [ ] Accessibility handled (minimum 48dp touch targets, font scaling)
- [ ] Tests added/updated
- [ ] Performance impact considered
- [ ] Documentation updated
- [ ] Build/tests verified
- [ ] No secrets or sensitive logs introduced
- [ ] Public API changes documented/versioned
