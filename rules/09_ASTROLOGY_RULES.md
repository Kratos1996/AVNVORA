# AYNVORA Astrology Rules
Version: 1.0

## Rule Registry
Every non-trivial traditional rule should have:
- stable rule ID
- tradition/source
- inputs
- conditions
- exceptions
- output
- interpretation metadata
- tests
- version

## Conventions
A calculation profile must explicitly define ayanamsa, house system, timezone handling and relevant tradition.

## Interpretation
Calculated fact, traditional rule, interpretation, prediction/timing and practical advice must be distinguishable.

## Change Control
Changing a calculation rule is a domain change and requires regression tests and version notes.
