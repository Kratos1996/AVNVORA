# AYNVORA Development Workflow
Version: 1.0

## Standard Flow
Requirement → specification check → reuse search → architecture check → security/privacy check → design-system check → implementation → tests → performance → documentation → review.

## AI/Codex Workflow
Before editing:
1. Read 00_MASTER_RULES.md.
2. Read the relevant domain documents.
3. Inspect existing implementation for reusable code.
4. Explain intended changes when the task is architectural or security-sensitive.
5. Implement the smallest coherent change.
6. Run the strongest available verification.
7. Report files changed, tests/builds run and remaining limitations.

## No Blind Coding
Do not allow an AI agent to modify the entire project without a scoped task and verification plan.
