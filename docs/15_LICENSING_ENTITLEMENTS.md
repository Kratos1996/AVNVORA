# AYNVORA Licensing & Entitlements
Version: 1.0

## Commercial Plans
Free, Monthly, Yearly, Lifetime, plus contract-defined add-ons.

## Entitlement Model
Feature visibility and capability are controlled by signed/versioned entitlements.

## Branding
Allowed customer customization:
- app/product name
- logo
- primary color
- secondary color

Core navigation, layouts, typography, astrology rules and core UX remain AYNVORA-controlled.

## Modes
- Powered by AYNVORA
- Co-branded
- Full white-label where contractually enabled

## Security
Client checks improve UX but are not the only protection for server-authorized capabilities.
